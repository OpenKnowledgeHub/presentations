## Presentations

This repo is a collection of several presentations to different IT topics. They are written with
the [reveal-js](https://github.com/hakimel/reveal.js/)
framework.

### Usage

The directory `src/roots` contains the html files of the different topics. If you want to run one specific presentation,
just simple copy the related `.html` file to `src/index.html` und run `npm run start`
